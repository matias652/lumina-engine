# Contributing to Lumina Engine

First off, thank you for considering contributing to Lumina Engine! I would be absolutely thrilled to have your help in building this framework. Whether it's a small typo fix or a major feature, every contribution counts and is deeply appreciated.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct (standard contributor covenant).

## How Can I Contribute?

### Reporting Bugs

- **Check the existing issues** to see if the bug has already been reported.
- **Open a new issue**, clearly describing the problem and including steps to reproduce it.

### Suggesting Enhancements

- **Open a new issue** with the tag "enhancement".
- Provide a clear and detailed description of the proposed feature.

### Pull Requests

1. Fork the repository.
2. Create a new branch for your feature or bug fix (`git checkout -b feature/your-feature`).
3. Make your changes.
4. Ensure your code follows the existing style.
5. Commit your changes (`git commit -am 'Add some feature'`).
6. Push to the branch (`git push origin feature/your-feature`).
7. Open a Pull Request.

## Styling Guidelines

- Use CamelCase for classes and methods.
- Use camelCase for variables.
- Use C++17 features where appropriate.
- Document new functions in the header files.

## Project Structure

- `include/LuminaEngine/`: Header files.
- `src/`: Implementation files.
- `examples/`: Example applications.
- `scripts/`: Lua scripts.
- `docs/`: Documentation.
