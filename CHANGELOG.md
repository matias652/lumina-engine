# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/en/2.0.0/).

## [1.0.0] - 2026-01-30

### Added
- Reorganized project structure for better modularity
- Improved scripts organization
- GitHub metadata (CONTRIBUTING, SECURITY, etc.)
- Expanded Lua API bindings
- Texture management system
- Sprite rendering system
- SDL3 integration for graphics and events
- Optional Box2D integration for 2D physics
- Scripting system with Lua/sol2
- Logging system
- Flatpak/Flathub configuration

### Features
- Engine initialization system
- Optimized main loop
- Event handling (window, keyboard)
- Basic rendering with SDL3
- Time management and deltaTime
- Lua bindings (Input, Graphics, Time)
- Sprite rendering system
- OpenGL ES 3.0 support
- CMakeLists.txt configured for installation
- Framework prepared for distribution
