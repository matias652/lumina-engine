# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

To report a security vulnerability, please open an issue with the "security" label or contact the maintainers directly if possible.

We will acknowledge your report within 48 hours and provide a timeline for a fix.
